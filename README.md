# Conway's Game of Life

<img width="1487" height="822" alt="image" src="https://github.com/user-attachments/assets/2e045f95-fb79-42d9-8836-50e9cdc90115" />

A browser-based implementation of **Conway's Game of Life**, a cellular automaton created by mathematician John Conway. Built using HTML, CSS, and vanilla JavaScript.

## Features

- Interactive grid for creating custom patterns.
- Play, pause, and resume the simulation.
- Adjust the simulation speed.
- Randomise or reset the grid.
- Live generation and speed counters.

## Rules

Each cell is either alive or dead. On each generation:

- Live cells with fewer than two live neighbours die.
- Live cells with two or three live neighbours survive.
- Live cells with more than three live neighbours die.
- Dead cells with exactly three live neighbours become alive.

## Getting Started

Clone the repository and open `index.html` in a web browser.

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
